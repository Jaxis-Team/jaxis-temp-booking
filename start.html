Pin the teacher's video so it stays put.

在班級頁面最上方，點綠色的 🏠 JINGS 訓練基地 按鈕。

畫面會顯示「Members only 會員專區」。輸入我們提供給你的專屬密碼，再按 ENTER。

Key in the passcode we gave you, then press ENTER.

大小寫、空格都沒關係。

👇 選擇你的裝置

1. 用 Safari 打開班級連結
2. 點下方中間的分享鍵 ⬆️
3. 往下滑，選「加入主畫面」
4. 按「新增」

⚠️ 一定要用 Safari，用 Chrome 找不到這個選項。

1. 用 Chrome 打開班級連結
2. 點右上角 ⋮
3. 選「加到主畫面」
4. 按「新增」

打開班級連結後，按 Ctrl + D（Windows）或 ⌘ + D（Mac）加入書籤。

⚠️ 請先加到主畫面，再點選上課天。主畫面的圖示和瀏覽器是分開記憶的，順序反了日期會不見。

打開班級頁面後，最上面有兩顆按鈕。告訴孩子記顏色就好：

🟢 綠色 — 🏠 JINGS 訓練基地
➜ 要練習遊戲就點這個
🔵 藍色 — 🎥 進入 Zoom 教室
➜ 要上課就點這個

Green = practise · Blue = class
